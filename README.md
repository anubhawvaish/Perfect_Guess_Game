# 🎯 Perfect Guess Game

A simple command-line number guessing game built using Python. The program generates a random number, and the player has to guess it. After each guess, the game provides hints indicating whether the guessed number is **too high** or **too low** until the correct number is found.

## 🚀 Features

* Generates a random number each time the game starts.
* Accepts user input through the terminal.
* Provides hints if the guessed number is too high or too low.
* Tracks the total number of attempts taken by the player.
* Displays a congratulatory message when the correct number is guessed.

## 🛠️ Technologies Used

* Python
* Random Module

## 📌 How to Play

1. Run the Python script.
2. Enter your guess when prompted.
3. Follow the hints ("Too High" or "Too Low").
4. Continue guessing until you find the correct number.
5. The game will display the number of attempts you took to win.
